- 每个页面目录统一拆分为 data.tsx（数据模型）、handler.ts（业务逻辑）、view.tsx（UI 渲染）、index.tsx（装配 ViewClass/DataClass/HandlerClass）四个文件。
- 框架层通过抽象基类定义契约：`HandlerBase` 封装 store 访问与网络请求，`DataBase` 提供静态 active 路径工具，`ViewBase` 作为视图基类，业务代码继承而非直接组合。
- 模块间通过 `alias.ts` 中定义的 `@/`、`@utils/`、`@handler/`、`@store/`、`@view/` 等路径别名引用，避免相对路径嵌套。
- 框架包将类型与实现分离导出：`index.ts` 同时 re-export 默认导出与命名类型（如 `Result`、`LogLevel`、`VProps.*`），对外暴露统一的 API 边界。
- Mock 服务按资源域划分路由目录（login、sys、demo），并在 `src/index.ts` 中以 `/api/<domain>` 前缀集中挂载。
