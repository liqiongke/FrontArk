仓库采用三层结构：
- `packages/framework`（@jl/framework）：以 Vite 构建的 React 组件库，通过 `src/index.ts` 统一导出 `ViewRoot`、`HandlerBase`、`DataBase`、`createUserStore` 等核心能力；内部按职责划分为 `comp/`（视图基类与控件）、`handler/`（业务处理器基类）、`stores/`（Zustand 状态管理）、`data/`（数据模型基类）、`utils/`（网络、日志、路径工具），并通过 `alias.ts` 中的 `@/`、`@utils/`、`@handler/` 等别名解耦模块依赖。
- `packages/mock`：独立的 Express 服务，提供 `/api/login`、`/api/menu`、`/api/demo` 等路由，使用 mockjs 生成测试数据，通过 nodemon 热重载开发。
- `apps/demo`：基于 Vite + react-router-dom 7 的演示应用，采用 `vite-plugin-pages` 约定式路由（`pages/base/*`、`pages/composite/*`），每个页面遵循 data/handler/view/index 四文件组织模式，通过 `layouts/main`、`layouts/login` 提供主布局与登录布局。
顶层 `turbo.json` 编排 build/dev/lint 任务，根 `package.json` 暴露 `pnpm` 脚本聚合各子包命令，依赖方向为 demo → framework ← mock，framework 仅被 demo 引用。
