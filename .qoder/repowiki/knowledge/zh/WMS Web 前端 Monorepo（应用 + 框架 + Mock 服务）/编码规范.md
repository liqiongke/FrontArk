- 每个页面目录遵循 data.tsx / handler.ts / view.tsx / index.tsx 四件套拆分，vite-plugin-pages 通过 exclude 规则排除 data/view/handler 仅将 index 注册为路由。
- 框架层通过抽象基类组织扩展点：HandlerBase 封装 store/net/getData/setData 等通用能力，DataBase 提供静态 active 路径工具，ViewBase 作为视图基类，业务代码继承这些基类复用能力。
- 框架内部模块通过 @alias（如 @utils、@stores、@comp、@data、@handler）导入，由 framework/alias.ts 集中维护并在 demo 的 vite.config.ts 中复用，保证跨包路径一致。
- store 使用 Zustand 创建并以 createUserStore 形式暴露，handler 通过 getModalHandler/getDrawerHandler 动态从 store 获取或实例化，形成 view ↔ handler ↔ store 的单向数据流。
