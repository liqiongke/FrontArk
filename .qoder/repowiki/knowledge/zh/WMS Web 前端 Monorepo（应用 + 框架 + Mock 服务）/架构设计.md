仓库采用 pnpm workspace + Turborepo 的 monorepo 结构：根 package.json 通过 turbo 脚本统一调度 apps/* 与 packages/* 下的 build/dev/lint；apps/demo 是基于 Vite + React 19 + Ant Design 6 的业务演示应用，使用 vite-plugin-pages 按 src/pages 目录自动路由，并通过 alias 直接引用 @jl/framework 源码进行本地联调；packages/framework 是内部 UI/数据框架，以 Zustand 管理 store、自定义 ViewRoot 作为视图容器，导出 HandlerBase/DataBase/ViewBase 等基类及 comp/view/handler/stores/utils 等子模块，通过 vite-plugin-dts 输出 .d.ts 类型；packages/mock 是基于 Express + MockJS 的独立 Node 服务，用于在 dev:mock 模式下提供假数据。依赖方向严格单向：demo → @jl/framework → 第三方库，mock 服务与 demo 通过 HTTP 解耦。
