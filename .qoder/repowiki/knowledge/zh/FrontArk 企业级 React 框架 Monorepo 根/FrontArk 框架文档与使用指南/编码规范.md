- 组件用法文档统一以「控件类型 → 配置示例」结构组织，每个控件通过 `{ title, field, ctrl: { type: Ctrl.Xxx } }` 形式展示声明式配置。
- 页面开发示例遵循 ViewRoot 三件套模式：同时提供 DataClass（继承 DataBase）、HandlerClass（继承 HandlerBase）、ViewClass（继承 ViewBase）三段代码片段。
- 布局与复合视图通过 VType.Layout*（Tab/Flex/Modal）组合多个子 viewId，并以 getRootId 返回根布局 id 的方式定义页面结构。
- Store 相关约定在文档中以表格和 JSDoc 引用方式强调：查询方法必须返回 store 内部已有引用或原始值，禁止新建对象/数组以避免无限重渲染。
