## 简介
本章节面向使用与二次开发该框架中"表格组件"的读者，系统性说明如何通过声明式配置生成复杂表格界面，包括列定义、搜索面板、数据绑定、行选择、虚拟滚动等能力；并结合示例页面展示与状态管理的数据同步机制。文档同时提供性能优化建议与最佳实践，帮助你在大数据量场景下获得稳定流畅的体验。

**最新更新**：表格组件现已支持订阅式渲染模式，通过 RenderMode.Subscription 启用细粒度单元格更新，避免全表重渲染，大幅提升频繁编辑场景下的性能表现。新增的 BoundTableCell 组件和 useRowIdentityList Hook 实现了行列分离的架构设计。

- 表格视图组件：负责读取视图配置与数据，组装列、搜索面板与 Ant Design Table，并启用虚拟滚动与自定义行组件。

- **增强**：路径计算工具类：提供智能路径合并与降级机制，确保数据绑定的稳定性。
- **新增**：活动路径管理器：getActivePath 函数支持智能路径降级，提升焦点行计算的灵活性。

### 表格视图（ViewTable）
- 职责
  - 读取视图配置与数据源
  - 根据 renderMode 选择渲染模式（经典模式或订阅模式）
  - 生成列配置并注入虚拟滚动、自定义行组件
  - 渲染搜索面板与表格主体
- 关键行为
  - 使用 useMemo 缓存列配置，避免重复计算
  - 通过 useRef 缓存滚动高度与组件实例
  - 将数据以数组形式传递给 dataSource，确保空数据安全
  - 开启虚拟滚动以提升大数据渲染性能
  - **新增**：双模式渲染支持，根据配置自动选择 Record 或 Subscription 模式
  - **增强**：智能路径降级机制，当view.path未定义时自动使用view.dataId作为基础路径

### 订阅式渲染模式（Subscription Mode）
- 职责
  - 提供高性能的表格渲染模式，避免全表重渲染
  - 通过行身份列表管理，实现行列分离的架构
  - 支持细粒度单元格更新，仅更新变化的字段
- 关键特性
  - 使用 useRowIdentityList 获取行身份列表
  - 自动检测行键有效性，无效时回退到经典模式
  - 通过 @Row 引用实现精确的数据寻址
  - 保持行身份对象跨版本复用，减少内存分配

**新增功能**：结构订阅模式
- 行身份列表：仅包含 {key: rowKey} 的轻量级对象
- 字段值订阅：单元格控件通过 @Row 路径自行订阅数据
- 性能优化：字段编辑不带动表格外壳更新
- 自动回退：行键缺失/重复/非字符串时自动回退经典模式

### 订阅式单元格组件（BoundTableCell）
- 职责
  - 实现按身份绑定的单元格渲染
  - 通过 memo 隔离行内其他字段修改的影响
  - 支持 @Row 引用和智能路径降级
- 关键特性
  - props 仅包含稳定身份（viewId/columnKey/rowKey）
  - 内部订阅列配置和基础路径，不受父组件更新影响
  - 优先使用 @Row 身份寻址，回退时使用下标寻址
  - 与 CtrlFactory 集成，支持任意控件渲染

**新增功能**：单元格隔离机制
- memo 包装：防止行外壳重渲染时不必要的单元格更新
- 路径订阅：单元格控件通过 useData 独立订阅字段值
- 身份优先：优先使用 rowKey 进行数据寻址，保证列表重排后仍指向正确记录

### 行身份列表管理（useRowIdentityList）
- 职责
  - 订阅表格基础路径下的数据数组
  - 提取有序行键序列，生成仅含行身份的 dataSource
  - 管理行身份对象池，实现对象复用
- 关键特性
  - 数据数组引用未变化时直接复用上次结果
  - 行键序列不变时复用行列表引用，避免不必要的重建
  - 行身份对象按键值跨版本复用，减少内存分配
  - 自动检测行键有效性，标记 fallback 状态

**新增功能**：结构订阅核心逻辑
- 行身份提取：从完整数据数组中提取 {key: rowKey} 的轻量级对象
- 对象池管理：使用 Map 缓存行身份对象，支持清理已删除的行
- 性能优化：通过 ref 缓存保证同输入返回同引用，满足 zustand v5 要求

## 性能考量
- 虚拟滚动：已启用虚拟列表，适合大数据量场景，降低首屏与滚动时的渲染压力
- 列配置缓存：通过 useMemo 缓存列配置，避免每次渲染重新计算
- 单元格更新策略：shouldCellUpdate 固定返回 false，减少细粒度重渲染开销
- 行组件优化：使用 useMemoizedFn 稳定回调引用，避免不必要重渲染
- 数据绑定：dataSource 仅在数据变化时更新，配合稳定的 rowKey 提升 diff 效率
- **新增**：订阅式渲染模式：避免全表重渲染，仅更新变化的单元格
- **新增**：行身份对象池：跨版本复用行身份对象，减少内存分配
- **增强**：路径计算缓存：PathUtils 内部对字面量路径进行缓存，避免重复计算
- **新增**：活动路径缓存：getArrayIndexByKey 使用 WeakMap 缓存索引，实现O(1)查找
- **新增**：单元格隔离：BoundTableCell 通过 memo 隔离行内其他字段修改的影响
- 建议
  - 合理设置列宽 width，避免频繁计算布局
  - 控制 searchItems 数量与复杂度，必要时分页加载或延迟渲染
  - 对复杂单元格内容考虑懒加载或虚拟化
  - 充分利用路径降级机制，减少不必要的path配置
  - 监控getActivePath调用频率，避免过多重复计算
  - **新增**：对于频繁编辑的大表格，建议使用订阅式渲染模式（RenderMode.Subscription）
  - **新增**：确保数据包含有效的 KeyAttr 字段，以充分利用订阅式渲染的性能优势

## 结论
该表格组件通过声明式配置实现了列定义、搜索面板、行选择与虚拟滚动等核心能力，并与框架的数据与视图状态紧密集成。**最新增强**的订阅式渲染模式通过 RenderMode.Subscription 提供了高性能的表格渲染方案，特别适合频繁编辑的大数据表格场景。新增的 BoundTableCell 组件和 useRowIdentityList Hook 实现了行列分离的架构设计，通过 @Row 引用实现精确的数据寻址，避免全表重渲染。getActivePath 函数的智能路径降级机制进一步提升了组件的兼容性和易用性。借助这些新特性，开发者可以构建出性能更优、用户体验更好的表格界面。在生产环境中，建议根据业务场景选择合适的渲染模式，对于频繁编辑的场景优先考虑订阅式渲染模式。
